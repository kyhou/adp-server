# Protocol proposals

Each proposal keeps its original text below a resolution notice. The active
specification is the repository-root [ADP-01.md](../../ADP-01.md).

| Proposal | Resolution |
|---|---|
| [canonical-hex-encoding.md](canonical-hex-encoding.md) | Accepted, scoped to fields ADP-01 explicitly defines as hexadecimal (ADP-01 §Canonical Hex Encoding) |
| [positive-listing-evidence.md](positive-listing-evidence.md) | Accepted in part, partially superseded by ADP-01 §Relay availability (freshness-sensitive operations, `503`, NIP-65 preference) |

A resolution records the protocol decision only. Whether the code conforms is
tracked separately in [protocol implementation gaps](../protocol-implementation-gaps.md).
