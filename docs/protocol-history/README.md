# Historical ADP protocol drafts

These snapshots are **superseded, non-normative drafts**, retained only for
historical reference. Their original contents, filenames and version identifiers
are preserved; relative links may refer to the drafts' original locations.

- `ADP-01-v0.1.md`: early badge-based design.
- `ADP-01-v0.2.md`: earlier receipt-based design.
- `ADP-01-v0.2-transition-draft.md`: earlier v0.2 transition draft.
- [ADP-01-amendment-free-acquisitions.md](ADP-01-amendment-free-acquisitions.md):
  free, promotional, and non-monetary acquisitions amendment (v3).
- [ADP-01-amendment-launch-profiles.md](ADP-01-amendment-launch-profiles.md):
  package format and launch profiles amendment (v1). This is the server
  repository's copy, which predates target-scoped `launch_default`; the
  Arcadestr repository's archived copy includes it.

Both amendments carry a superseded notice and are otherwise unmodified. Their
requirements are consolidated into the repository-root [ADP-01.md](../../ADP-01.md),
which is the only active specification. Where they differ from it, ADP-01 governs.

These files do not define current implementation requirements. Documents under
[proposals](../proposals/README.md) record their resolution status individually.
